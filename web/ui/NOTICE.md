# Courier UI asset notice

The Courier logos, functional icon geometry, visual tokens, and Relay pigeon mascot are Courier project assets distributed under the repository MIT license.

The compact 8-bit Relay pigeon family was created with the built-in OpenAI image generation workflow from the direction recorded in [`docs/brand.md`](../../docs/brand.md). Neutral-v1 is the canonical identity reference for mark/route/delivery/admin-v2. Those variants preserve the same physiology, proportions, plumage, eye, beak, earpiece, satchel, and palette and vary only pose, role equipment, or carried objects. All five transparent rasters are stored locally and verified through `assets/provenance.json`; generated scenery is not shipped. The manifest records each exact prompt, identity-reference lineage, consumer, role, dimensions, byte count, SHA-256 digest, and QA contact sheet. WebP delivery copies were nearest-neighbor resized, reduced to a shared hard 32-color treatment, and encoded losslessly. Temporary studies and superseded role-v1, armored, Robocop-style, moth, swift, realistic-pigeon, wide-wing, panorama, and cyberpunk-city assets are not shipped.

Browser-injected scripts, remote resources, reference-page executable code, obsolete mascot art, generated backgrounds, and mirror-oriented artwork or messaging were deliberately excluded.
