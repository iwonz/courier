# Design: Seamless UI polish

## Visual hierarchy

Courier uses one continuous document canvas with spacing, tone, and typography as the primary hierarchy. Borders are reserved for inputs, focus, destructive emphasis, and the few boundaries that communicate real grouping. Default cards become quiet translucent surfaces without outlines or large shadows. Nested card-on-card composition is removed.

The landing route hero and route controls become one composition. Installation flows without section-edge rules. The CLI registry uses one shared surface with internal responsive division rather than two independent bordered cards. Delivery manifests and administration navigation/inspection follow the same rule.

## Compact brand mark

The full Relay mascot remains the editorial illustration. A second transparent square raster is generated specifically for product chrome: an architectural head-and-shoulders pigeon device with a broad, near-square silhouette, no feet, perch, tail fan, or rounded chicken-like body. `Brand` uses this mark with the literal wordmark `COURIER CLI`; `Mascot` continues using the full illustration.

## Preferences and navigation

The locale button renders the flag of the current locale (`🇬🇧` or `🇷🇺`) as its visible icon. Its accessible name still identifies current and next locale. The theme, locale, GitHub, and refresh icon actions share the same quiet control treatment. On the landing, brand and in-page navigation form the left cluster while external and preference actions remain right-aligned.

## Boundaries

No product behavior, route contract, API, secret handling, copy behavior, or preference cycle changes. The new mark is local, checksum-recorded, and contains no text or required information.
