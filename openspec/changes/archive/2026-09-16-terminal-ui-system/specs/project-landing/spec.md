## ADDED Requirements

### Requirement: Terminal-composed illustrated landing

The project landing SHALL use separately composed wide and portrait cinematic Relay scenes for hero, routing, installation, and CLI reference. Each scene SHALL reserve quiet space for a transparent terminal workspace. The stationary base MAY receive a non-essential smooth multi-lobed fine-pointer highlight and restrained refraction. The hero SHALL remain non-interactive and SHALL depict a decorative handoff between circular `Source` and `Destination` terminals.

#### Scenario: A fine pointer crosses a scene

- **WHEN** it moves over the base, refracted, glow, or veil layers
- **THEN** the local effect follows smoothly without hit-test jitter, base translation, functional state change, or continuous work after convergence

### Requirement: Terminal route demonstration

Courier SHALL present compact Source and Destination selection above a transparent terminal demonstration. Activation SHALL update a measured Bezier connector, immutable generated command, copy action, concise explanation, applicable options, and resettable preview transcript without maintaining a second capability list.

#### Scenario: A visitor runs a route preview

- **WHEN** the selected contract-backed route is activated through Run demo
- **THEN** the transcript presents preflight, routing, transfer preview, verification, and completion while stating that no data left the page

### Requirement: Terminal installation demonstration

Courier SHALL present compact icon-led installation choices above one transparent immutable command demonstration with copy, Run demo, repository release actions, and invariant geometry.

#### Scenario: A visitor runs an installation preview

- **WHEN** Run demo is activated for the selected channel
- **THEN** the transcript previews release resolution, platform selection, download, checksum verification, and installation without executing the command

### Requirement: Terminal CLI demonstration

Courier SHALL present generated commands and compatible options as transparent terminal panes and SHALL provide copy and read-only help demonstration actions only while a command is selected.

#### Scenario: A visitor runs a command help preview

- **WHEN** a command is selected and Run demo is activated
- **THEN** the transcript derives usage, options, defaults, and successful completion from the generated contract without editable input or execution

### Requirement: Transparent masthead integration

Courier SHALL keep the safe-area-aware measured masthead permanently visible using a transparent multi-stop scene fade and masked backdrop blur without an opaque band or lower rule.

#### Scenario: A visitor scrolls across contrasting scenes

- **WHEN** any slide aligns with the viewport
- **THEN** navigation and actions remain legible while the masthead blends gradually into the scene and remains fully within the visual viewport
