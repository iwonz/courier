# Change: Vivid editorial flow

## Why

The current engraved panorama and viewport-sized section geometry make Courier feel muted, heavy, and divided into artificial screens. The artwork behaves as wallpaper instead of supporting the product interaction, while oversized vertical constraints leave unnecessary empty space.

## What Changes

- Replace the carbon-and-chalk moth direction with a vivid, mature editorial courier identity led by an ImageGen-authored raster swift mascot.
- Remove the full-page panorama and present one responsive, content-aware hero illustration inside the first section.
- Let hero, installation, and CLI sections use natural document height with compact responsive spacing and no viewport-height targets.
- Refresh shared color, surface, header, workbench, command, endpoint, and channel styling with rounded kinetic geometry and stronger readable contrast.
- Preserve every route, installation, command, preference, accessibility, API, and security behavior.
- Update local asset provenance, budgets, documentation, and browser acceptance.

## Impact

This changes browser presentation and generated identity assets only. Public CLI behavior, HTTP APIs, release behavior, delivery security, and the command contract remain unchanged.
