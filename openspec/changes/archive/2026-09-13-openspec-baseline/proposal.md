# Change: Establish the OpenSpec baseline

## Why

Courier's completed changes remain active, so later changes cannot reliably modify a consolidated specification baseline.

## What Changes

- Archive completed changes 001 through 011 in implementation order.
- Consolidate their requirements under `openspec/specs` without changing runtime behavior.
- Document the archive-first lifecycle for future stacked tasks.

## Impact

This is a specification-workflow change only. Runtime code and public behavior remain unchanged.
